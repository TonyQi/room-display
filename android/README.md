# 房间状态 Android 应用

## 构建
- JDK 17、Android SDK Platform 35 / Build Tools 35.0.0、Gradle 8.11.1。
- 设置 `ANDROID_HOME` 或在本目录 `local.properties` 设置 `sdk.dir`。
- `gradlew.bat assembleDebug`（Windows）或 `./gradlew assembleDebug`（Linux）；输出 `app/build/outputs/apk/debug/app-debug.apk`。
- 正式发布使用自有签名密钥构建 release，不把 debug 签名用于正式分发。

## 首次操作
1. 安装后首次设置本机管理员密码，至少6位；没有内置默认密码。
2. 长按房间名称2秒输入密码，进入本机设置；编辑房间号、名称、状态名称/颜色/图标。
3. 选择“连接服务器”，输入 `http://10.0.2.2:8080`（Android官方模拟器访问宿主机），真实设备使用服务器局域网IP。
4. 保存后输入服务器部署时配置的 `ROOM_ENROLLMENT_KEY`。这不是服务器管理员密码。注册密钥不保存于设备；返回的设备凭据保存在应用私有存储。
5. 管理端会出现设备；切换本地状态免密码，远程指令保存后通过下一次同步确认。
6. 网络失败后持续重试，本地操作不受影响；配置编辑期间发生远程更新时会拒绝旧编辑内容，提示重新打开。

## 单机与同步
所有数据以一个JSON保存到SharedPreferences，每次commit成功才替换内存状态。本地状态修改和远程应用受同一锁保护。远程指令只有baseRevision匹配且未过期才执行，执行结果与revision、快照一起提交，回执供下一次同步重传。服务器地址变更会生成新设备编号、清空旧凭据，避免跨服务器混用。

使用HTTP只适用于受信任局域网；正式部署建议反向代理HTTPS，并使用可信证书。本应用不绕过TLS证书校验。

## 持续亮屏与专用设备锁定
应用在前台时持续亮屏并隐藏系统栏。普通安装只能保护应用内返回/退出，不能保证阻止系统主页、通知栏或多任务。

专用设备可在无账号、符合设备所有者配置条件的设备上，由部署人员授予设备所有者角色：

    adb shell dpm set-device-owner com.roomdisplay.app/.RoomAdminReceiver

随后在本机设置启用“专用设备锁定”。这会调用Android LockTask并锁定为专用模式：仅保留系统信息（时钟/电量），拦截系统主页、多任务、通知栏和电源菜单（Android 9及以上通过setLockTaskFeatures显式限制）；应用每次回到前台自动恢复锁定，必须通过管理员密码走“退出应用”退出。已在官方模拟器（Android 11）验证拦截有效。不要在用户日常个人设备上未经评估执行；厂家固件能力需实机验证。清除应用数据/卸载会清除本机密码、身份及数据，重新注册会显示为新设备。

## 测试操作定位
UI均为原生View，可通过UIAutomator按中文文字定位：首次“新密码（至少6位）/确认新密码/保存密码”；长按房间名称2秒；“管理密码/进入管理”；“服务器地址/连接服务器/保存本机设置”；“设备注册密钥/注册并连接”；“切换房间状态”。没有测试后门、预填生产密钥或跳过认证接口。

## 兼容范围
minSdk23 (Android6.0)，target/compile35；横竖屏由设置切换。真实13.3英寸设备的显示密度、系统管理能力和Android版本尚待实机验证。
