# 房间状态管理端（Vue 3）

真实管理端源码，无模拟设备或本地假后台。沿用已确认的深色科技界面，设备数量不固定；支持20–30台及后续扩展，每页12台。

## 构建与开发

需要 Node.js 20.19+ 或 22.12+（本次使用24.x）、npm。

```sh
npm ci
npm test
npm run build
```

构建产物写入 `../target/classes/static`，只清理该静态目录。日常构建在上级`server/`目录执行`mvn package`即可，管理端构建已集成到Maven生命周期，打出的JAR已包含网页；下方`npm ci / npm test / npm run build`供独立开发时使用。最终用户只需运行Java服务，无需安装Node.js；浏览器访问服务器的8080端口。

本地开发：先启动Java服务，再执行 `npm run dev`。Vite仅监听127.0.0.1，`/api`代理至 `http://127.0.0.1:8080`。若后端端口变化，修改vite.config.js中的proxy。

## 功能与数据来源

- 管理员真实登录、退出、修改密码；Bearer会话令牌仅在当前标签页sessionStorage保留，失效后重新登录。
- 每2秒读取真实设备、模板、操作日志。网络失败明确展示最近数据并暂停远程操作。
- 房间总览与设备列表支持搜索、连接筛选、分页、跨页选择。设备注册在Android端完成，后台提供接入说明。
- 状态切换、房间编辑及模板下发均提交完整快照和设备版本号；收到设备确认前不会在前端虚构新状态。
- 模板保存与下发分开。批量下发明确覆盖目标状态目录和当前状态，离线或有待确认指令的设备不可选。逐台显示提交结果，最终执行结果在日志中查看。
- 模板增删改、真实操作日志导出、管理员密码修改。
- 新注册但未同步设备的snapshot=null安全显示等待同步。
- 所有动态文本使用Vue插值，无HTML字符串注入。

## 接入与权限

首次管理员账户与密码来自服务器部署配置；无内置通用密码。设备注册密钥首次部署来自服务器环境变量ROOM_ENROLLMENT_KEY，可在系统设置中查看与更换，已注册设备不受更换影响。浏览器管理员密码和设备本地管理员密码独立。

正式使用受信局域网HTTP或HTTPS反向代理；浏览器与API建议同源。无需外部CDN。

## 测试

`npm test`运行搜索、状态模板复制、引用校验及状态配置校验的单元测试。

`tests/browser-smoke.mjs`是浏览器界面隔离测试，通过Playwright拦截API响应，测试用fixture不会进入正式构建。需自行安装Playwright并设置PLAYWRIGHT_MODULE（或将Playwright安装到可解析路径），运行Vite后执行该脚本。可用WEB_TEST_URL覆盖测试地址。

`tests/real-e2e.mjs`用于真实Java服务联调：从工作目录的 `work/test-credentials.json` 读取测试环境凭据 `{username,password,enrollmentKey,url}`。仅在独立测试数据库运行，它会注册 `web-test-` 前缀测试设备和模板并执行真实命令；不要在生产数据库执行。脚本模拟设备协议客户端确认指令，并用真实浏览器操作管理端。测试报告输出work，报告不包含密码或注册密钥。

本次验证通过：4项单元测试；浏览器fixture流程；真实Java登录/错误密码/空快照/状态命令ACK/房间资料ACK/模板创建与批量ACK/真实日志/过期会话；窄屏无页面级横向溢出。npm audit为0项已报告漏洞（仅代表检查时的依赖审计结果）。
