# 已确认设计与实现范围
- 设备APK：Kotlin原生界面，支持横竖屏、本地房间/状态编辑、状态免密码切换、管理员密码、持续亮屏、可选设备所有者锁定。
- 服务器：Java17 / Spring Boot；H2嵌入式持久数据库，适合20–30台设备的小规模局域网部署。
- 管理端：Vue3，无演示设备数据；登录后查看真实注册设备，模板/房间/状态修改通过设备确认后生效。
- 设备2秒HTTP同步。15秒无心跳离线，指令15秒失效。revision比较与ack去重，重连优先上传本地快照。
- Windows开发测试，同时交付Linux启动脚本和可选systemd单元，不自动安装服务。
- Android版本未知，先以Android6.0/API23为最低候选兼容范围，实际设备需复核。
- 不将模拟器/接口测试等同于真实13.3英寸设备验收。
